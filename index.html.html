ซิงค์ข้อมูลทุกหมู่บ้านแบบ Real-time โดยแยกบันทึกเป็นรายโครงการ ไม่ทับข้อมูลระหว่างเจ้าหน้าที่

กลไกป้องกันการทับข้อมูล

  • แยก Document ID: ระบบสร้าง ID เฉพาะรายการ ไม่มีการส่งตารางทั้งชุดไปเขียนทับข้อมูลของผู้อื่น
  • รันลำดับต่อท้าย: หากมีผู้ใช้ลำดับเดียวกันในหมู่บ้านไปก่อนแล้ว ระบบจะจัดลำดับถัดไปให้โดยอัตโนมัติ
  • ซิงค์ทันที: เมื่อเจ้าหน้าที่ท่านอื่นบันทึกจากอีกเครื่อง ข้อมูลจะอัปเดตลงตารางและรายงานแบบ Real-time

ตารางจัดการข้อมูลและจัดลำดับความต้องการ

ปรับลำดับความต้องการรายหมู่บ้าน ค้นหา แก้ไข และผสานข้อมูลจากหลายเครื่องโดยไม่ทับกัน

ลำดับความต้องการ ปีงบฯ หมู่บ้าน ชื่อโครงการ / รายละเอียดปริมาณงาน งบประมาณ (บาท) ความเร่งด่วน ผู้บันทึก / แก้ไข จัดการ

ระบบเชื่อมต่ออัตโนมัติจากค่า Config ที่ฝังไว้ หรือปรับเปลี่ยนค่าเองได้

บันทึกแยก Document อิสระ (Non-Overwriting):

เจ้าหน้าที่สามารถกรอกข้อมูลจากหลายอุปกรณ์พร้อมกันได้โดยข้อมูลจะไม่ถูกบันทึกทับกัน ข้อมูลจะถูกจัดเก็บเข้าสู่ Firestore Collection แยกเป็นรายโครงการ

สามารถระบุค่า Config ได้โดยตรงในโค้ดส่วน `EMBEDDED_FIREBASE_CONFIG` เพื่อให้ระบบเชื่อมต่อให้อัตโนมัติ
